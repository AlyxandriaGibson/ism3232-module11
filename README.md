## ISM3232 Lab 10: OOP for Agents

This FAQ Assistant (`FAQAssistant`) answers general store policies and operational questions for Tampa Outfitters by using an underlying lookup tool (`FAQKnowledgeBase`). This assistant operates as a rule based prototype which utilizes keyword matching and mock data structures instead of a fully autonomous. Requests regarding financial transactions, returns, or disputes are passed directly to a human agent, as it involves sensitive information and cannot be securely handled by this bot, as well as automated keyword lookups not being able to make policy exceptions. If this system were to be connected to real customer data without safeguards, rule matching errors or unverified inputs could expose sensitive personal information or trigger unauthorized account actions.
